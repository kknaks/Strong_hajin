디자인 시스템 v2

개인 워크스페이스용 업무 기록 앱. 요청자·담당자·참조 개념이 없고, 모든 기록은 본인이 등록합니다. v1(홈화면 추출 스펙)에 타입 스케일·그림자·아이콘·버튼·폼·상태·테이블·캘린더를 추가한 버전입니다.

00 — v1 에서 바뀐 것

새로 그리는 화면은 이 문서를 기준으로 합니다. 기존 14장 화면정의서와 어긋나는 항목은 변경 으로 표시했습니다.

Primitive(원시 색값)와 Semantic(의미 이름) 두 층입니다. 화면과 프롬프트에서는 Semantic 이름만 씁니다 — gray-500이 아니라 Text Tertiary라고 부릅니다. 이름이 "어디에 쓰는지"를 담고 있어야 사람도 AI도 틀리지 않습니다.

순수 회색을 없앴습니다. v2까지는 #757575·#B3B3B3가 순수 무채색(B−R = 0)이고 #5F6470·#9EA2AE는 블루 계열이라, 나란히 놓이면 무채색 쪽이 누렇게 보였습니다. 8단계 전부 색상(Hue) 220으로 통일했습니다.

밝기는 그대로입니다. 기존 값과 상대휘도 차이가 ±0.02 이내라, 이미 그린 14장 화면의 무게감은 바뀌지 않습니다. 색온도만 옮겨집니다.

캡션이 밝아졌습니다. 기존 캡션 색 #9EA2AE는 2.55:1로 AA 미달이었습니다. Text Tertiary(4.69:1)로 올렸으니 12px 캡션이 조금 진해 보입니다.

Surface(#FFFFFF)는 스케일 밖입니다. 카드·패널·드로어·모달의 바탕은 항상 흰색이고, 그레이 스케일에 포함하지 않습니다.

홈 3열이 360 / 560 / 672에서 392 / 600 / 600으로 바뀝니다. 기존 값은 어떤 컬럼 시스템에서도 나오지 않는 숫자라, 새 화면을 그릴 때 참조할 근거가 없었습니다. 새 값은 392 + 600 + 600 + (거터 24 × 2) = 1640으로 정확히 맞습니다. 시각적 차이는 30~70px이라 거의 느껴지지 않습니다.

고정 크롬은 그리드 밖입니다. 사이드바 200과 캘린더 좌측 레일 260은 컬럼에 맞추지 않습니다. 화면 구조를 지탱하는 고정 요소이고, 컬럼에 억지로 맞추면 미니 캘린더 같은 내용물이 깨집니다. 이 둘만 예외이며, 새로운 고정 크롬을 임의로 만들지 않습니다.

16 — RULES

화면을 추가할 때 어기면 안 되는 것들. 문서에 없는 상황이 나오면 여기부터 보고 판단합니다.

1. 사람 표기 없음
요청자·담당자·참조 아바타를 카드·리스트·테이블·캘린더·로그에 넣지 않습니다. 그 자리는 업무 유형 배지가 씁니다. Avatar를 쓰는 곳은 사이드바 프로필·홈 상단·드로어 헤더 셋뿐입니다.
2. #7181F8은 액션과 완료에만
버튼·전송·D-day·AI 강조, 그리고 완료 상태. 진행중은 #33AAFF, 시작전은 #6D7483. 흰 글자를 얹을 때만 #5467F7.
3. 검정은 위치, 보라는 선택
#1B1E25는 현재 위치 표시(사이드바, 뷰 전환, 탭, 오늘)에만 쓰고 화면당 하나. 필터 칩·체크·선택 카드는 #F1F2FE + #5467F7. 토스트는 예외.
4. 편집은 드로어, 결정은 모달
값을 여러 개 넣으면 드로어(840), 되돌리기 어려운 결정 하나는 모달(600), 고르기는 팝오버. 드로어 위에 모달을 겹치지 않습니다.
5. 업무 유형은 4개 고정
미팅·회의 / 개인 업무 / 문서·보고 / 취소. 새 배지 색을 임의로 만들지 않습니다. 캘린더 일정 블록도 이 4색만 씁니다.
6. 채널 색은 별개 축
메일·카카오톡·슬랙 색은 출처 표시 전용이며 업무 유형 배지와 섞어 쓰지 않습니다. 채널이 늘어나면 02에 먼저 등록합니다.
7. 그라디언트는 홈만
Hero Gradient는 홈 상단 400px과 로그인 좌측 패널에만. 앱 안쪽은 흰 배경 + breadcrumb + 타이틀로 시작합니다.
8. 행간과 자간은 손대지 않음 신규
모든 텍스트는 145% / −2%입니다. 특정 자리만 촘촘하게 만들지 않습니다. 높이가 안 맞으면 행간이 아니라 패딩으로 맞춥니다.
9. 그림자는 6개뿐 신규
06의 sm·md·lg·xl·drawer·ai 외에는 쓰지 않습니다. 새 그림자가 필요해 보이면 높이 단계가 잘못 잡힌 것입니다.
10. 상태는 네 가지를 항상 함께 신규
데이터를 보여주는 화면은 정상 · 로딩 · 비어 있음 · 실패 네 가지를 같이 그립니다. 정상만 그린 화면은 미완성입니다.
11. 색은 Semantic 이름으로만
화면과 프롬프트에서 gray-500·indigo-600이라 부르지 않고 Text Tertiary·Action이라 부릅니다. 보더는 외곽 Border Strong, 내부 Border Default, 행 구분 Border Subtle 세 단계뿐입니다.
12. 단축키는 보조 · 스코프는 필수
Enter·Esc로 동작해도 화면에는 버튼을 둡니다. 기간이 있는 화면은 타이틀 옆 Period Stepper로 현재 범위를 항상 노출합니다.
