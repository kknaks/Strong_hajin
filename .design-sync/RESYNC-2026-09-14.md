## 3. `dtsPropsFor` 대조 — **소스와 달랐던 항목 전수**

구 20종 중 **13종이 틀려 있었다.** 원인은 바퀴 11(「부품은 말을 모른다」)이 문구를 prop 으로 올린 것이다.
전부 **문서를 소스에 맞췄다**(반대 아님).

### (가) 없던 prop 이 **필수**로 생긴 것 — 12종

| 부품 | 구 문서 | 실제 소스 |
|---|---|---|
| `ProgressBar` | `label?`·`done`·`total` | **`ariaLabel` 필수 추가** |
| `Drawer` | `closeLabel` 없음, `size` 없음 | **`closeLabel` 필수** · `size?: "sm"\|"lg"` (기본 `lg`, G-10) |
| `ConfirmModal` | `cancelLabel`·`closeLabel` 없음 | **`cancelLabel: string \| null` 필수** · **`closeLabel` 필수** |
| `Toast` | `closeLabel` 없음 | **`closeLabel` 필수** |
| `Select` | `labels`·`emptyActionLabel` 없음 | **둘 다 필수**(`labels` 6키) |
| `MultiSelect` | 〃 | **둘 다 필수** |
| `TimeField` | `labels`·`emptyActionLabel`·`selectLabels` 없음 | **셋 다 필수**(6키+6키) |
| `TimeRangeField` | 위 셋 + `startLabel`·`endLabel` 이 `?` 였다 | **다섯 다 필수** |
| `DatePicker` | `today`·`labels`·`weekdayNames`·`formatMonth` 없음 | **넷 다 필수** |
| `DateField` | 〃 + `displaySeparator`·`pickerIcon`·`required` 없음 | **넷 필수 + 선택 셋 추가** |
| `Skeleton` | `label?` (선택) | **`label` 필수** |
| `MinWidthNotice` | 「props 없음」 | **`title`·`description` 필수** ← 구 문서가 정면으로 틀렸다 |

### (나) 값 집합이 바뀐 것

- **`Icon.name`** — 구 문서 27종 중 **6종이 없는 이름**이었다:
  `check-square`→`square-check` · `list`→`list-category` · `refresh`→`reset` ·
  `alert`→`circle-exclamation` · `empty`→`inbox` · `filter`→`tune`.
  실제는 **35종**(24그리드 26 · 16그리드 8 · 면 1). `square`·`circle`·`empty` 폐기라던 원 문서 기술도
  틀렸다 — `circle` 은 살아 있고 `square`·`empty` 는 이름이 바뀐 것이다.
- **`Empty`** — 구 문서는 `actionLabel?`·`onAction?` 을 각각 선택으로 적었다. 실제는 `EmptyAction`
  유니온이라 **이름 없이 행동만 넘기면 컴파일이 안 된다**. 프리뷰 `Filter`·`Error` 스토리가 정확히
  그 모양이어서 깨져 있었다.
- **`Badge`·`Button`·`Chip`·`IconButton`·`DataTable` 의 `...rest`** — 남은 DOM 속성을 전부 통과시킨다는
  사실이 구 문서에 없었다(`data-status`·`title`·`aria-pressed`·Popover 트리거 aria).
- **`Toast.tone`·`Drawer.size`** 등 「v2 확장」 표기를 새 DS 어휘로 고쳐 썼다.

### (다) 검증 방법

구조분해 인자와 타입 리터럴을 괄호 균형으로 파싱해 **prop 이름 집합**과 **필수/선택 표시**를 34종 전부
기계 대조했다 — 둘 다 불일치 0. 여기에 프리뷰 타입 검사(0 에러)가 **호출 가능성**까지 확인한다.

## 4. 프리뷰 34종 — 문구 prop 때문에 손이 더 간 것

**전면 재작성 4** — 구 어휘가 죽어 있었다:

- `Skeleton` — `NoDelay` 우회(`.skeleton-bar{animation-delay:0s}`) **삭제**. 새 `.scax-skeleton` 에는
  지연이 없어서 우회가 죽은 코드였다.

**문구 prop 때문에 고친 9**: `ConfirmModal`(cancel/close) · `Toast`(close) · `ProgressBar`(ariaLabel) ·
`MinWidthNotice`(title/description) · `Skeleton`(label) · `Select`·`MultiSelect`(labels 6키 + emptyActionLabel) ·
